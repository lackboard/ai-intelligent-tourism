# 西安旅游全攻略与避坑指南

西安作为十三朝古都，历史文化底蕴深厚。为了让您的旅途更加顺畅，特整理本指南。

## 1. 核心景点介绍

### 1.1 秦始皇兵马俑博物馆
* **门票价格**：成人票 120 元/人，学生票半价。
* **建议游玩时间**：3-4 小时。
* **核心看点**：一号坑（最大、最震撼）、二号坑（兵种最全）、三号坑（指挥部）、铜车马展厅。
* **注意事项**：距离市区较远（临潼区），建议预留半天时间。

### 1.2 西安城墙
* **门票价格**：54 元/人。
* **游玩建议**：强烈建议在城墙上租自行车骑行（单人车 45 元/3 小时），或者傍晚时分在南门（永宁门）看日落和夜景。

## 2. 美食与避坑指南 (必看)

### 2.1 美食街区选择
* **❌ 避坑点（回民街主街）**：钟楼背后的回民街主街商业化严重，物价偏高，本地人极少去这里吃饭。
* **✅ 推荐点（洒金桥 / 大皮院）**：距离回民街不远，是真正本地人去的小吃街。推荐品尝：胖子甑糕、志亮灌汤蒸饺、刘信牛羊肉泡馍。

### 2.2 交通与黑车避坑
* **火车站黑车**：在西安火车站或高铁站出站时，**绝对不要**乘坐主动搭讪的“黑车”或黑导游提供的“兵马俑一日游”大巴。
* **假兵马俑**：小心被黑车司机拉去“世界八大奇迹馆”或“溯源秦皇陵”等山寨人造景点。去兵马俑请认准在火车站乘坐正规的 **游5 (306路)** 公交车，或直接打网约车。

## 3. 当地旅游政策
* **预约制**：陕西历史博物馆实行**全面预约制**，不售当日票。旺季必须提前 3-7 天在官方公众号抢票（每天放票时间为 10:00、11:00、18:00、19:00）。
* **地铁乘车**：西安地铁支持微信/支付宝乘车码，无需单独下载 APP。
