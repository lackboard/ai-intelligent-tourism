# RAG 检索测试问题集合

以下问题可用于评估检索、重排、摘要、规则问答、多文档对比等能力。

## 1. 单文档精准问答

1. 北京三日游中，第二天主要推荐去哪里？
2. 北京攻略里，故宫建议预留多长时间？
3. 成都攻略中，为什么不建议把宽窄巷子当成主要吃饭地？
4. 西安攻略里，兵马俑建议预留多久？
5. 三亚避坑指南提到预订潜水套餐前需要确认哪些事项？
6. 杭州攻略里，为什么说西湖不适合“走马观花”？
7. 重庆夜景指南里，为什么地图上看着近的地方实际不好走？
8. 鼓浪屿轮渡模拟规则里，开航前多久停止检票？
9. 青海湖生态管理模拟规则里，车辆可以停在哪些区域？

## 2. 多文档对比问答

1. 哪些城市更适合慢节奏旅行？
2. 哪几份文档都提到了旺季、节假日或高峰时段要提前规划？
3. 哪些文档都强调不要把行程排得太满？
4. 哪些地方更适合夜游？对应的风险点分别是什么？
5. 哪两份文档都提到了“预约”或“实名核验”？

## 3. 规则类问答

1. 如果游客因个人原因错过鼓浪屿船班，是否保证免费改签？
2. 鼓浪屿规则中建议提前多久到达候船区？
3. 青海湖模拟规定中，哪些行为会被限制进入或劝阻？
4. 青海湖文档里，无人机在哪些区域不能擅自飞行？

## 4. 摘要类任务

1. 用 5 句话总结三亚避坑指南。
2. 提炼一份北京三日游的极简行程。
3. 总结西安历史旅行的安排逻辑。
4. 提炼重庆夜景避坑的三条核心建议。

## 5. 改写与结构化抽取

1. 从所有文档中抽取“城市—适合游玩天数—适合人群”。
2. 从所有文档中抽取“景点/地区—主要风险—建议做法”。
3. 从政策类文档中抽取“适用范围、禁止事项、游客建议、典型问答”。
