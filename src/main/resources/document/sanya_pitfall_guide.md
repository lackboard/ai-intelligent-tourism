# 三亚旅游避坑指南

## 1. 这份指南适合谁

- 第一次去三亚的游客
- 对预算敏感的人
- 想体验海边度假，但担心被“景区消费”影响体验的人

## 2. 高频踩坑场景

## 2.1 海鲜加工与点单不清

### 常见问题
- 没问清楚加工费、称重方式、配菜和额外服务费
- 看似单价不高，但最终结算偏高

### 建议做法
- 点单前确认**海鲜单价、加工费、总量、做法**
- 尽量保留菜单或点单记录
- 不要在价格含糊时默认“差不多就行”

## 2.2 景区附近水果和特产“游客价”

### 常见问题
- 包装精美但单价偏高
- 试吃热情，但结账时价格超预期

### 建议做法
- 先问**每斤还是每份**
- 问清楚是否已经切好、是否计包装费
- 不要因为不好意思拒绝而购买超预算商品

## 2.3 低价旅拍、低价游艇、低价潜水套餐

### 常见问题
- 宣传价格低，但后续层层加项
- 包含项目与实际体验不一致
- 出片数量、修图张数、服装套数不透明

### 建议做法
- 预订前看清：
  1. 基础价格包含什么
  2. 是否强制升级套餐
  3. 取消和改期规则
  4. 成片交付时间

## 2.4 租车与电动车押金

### 常见问题
- 取车前没拍照，归还时容易产生争议
- 押金退还周期模糊
- 保险范围不清楚

### 建议做法
- 取车和还车时全方位录像
- 明确押金金额、退还时间、违章处理方式
- 不要只看日租金，忽略保险与附加费用

## 2.5 临时更改海上项目行程

### 常见问题
- 天气变化导致项目取消或延后
- 商家以“不可抗力”为由不清晰处理退款

### 建议做法
- 预订前明确退款条款
- 遇到大风、强降雨时以安全为先
- 把高依赖天气的项目安排在行程前半段，给自己留出调整空间

## 3. 住宿避坑

### 3.1 “海景房”不一定是正海景
- 预订前确认房型说明
- 注意“侧海景”“远海景”“部分海景”的区别

### 3.2 淡旺季价格波动大
- 节假日前后房价差异可能非常明显
- 建议对比多天价格，不要只看某一天

### 3.3 离海近不等于出行方便
- 有些酒店虽然近海，但离餐饮、便利店、公共交通较远
- 适合纯度假，不一定适合高频出门游玩

## 4. 饮食建议

- 不要连续多顿重口味海鲜烧烤
- 海边暴晒后注意补水
- 肠胃敏感人群尽量避免“生冷 + 酒精 + 高油高辣”组合

## 5. 行程建议

### 更推荐的安排方式
- **一天一个核心主题**：海边、免税店、雨林、海上项目分别安排
- 给天气留机动时间
- 把最期待的项目放在前两天完成

### 不推荐的安排方式
- 抵达当天安排潜水、游艇、旅拍等多个项目
- 每天跨区域多次折返

## 6. 一句话总结

三亚真正容易踩坑的不是“景色”，而是**信息不透明的消费场景**：只要把价格、包含内容、退款规则提前问清，大部分坑都能避开。
